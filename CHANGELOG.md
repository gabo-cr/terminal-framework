# Historial de versiones

Cambios comprobados contra el código y el historial de Git.

## v0.2.0 — Autocompletado y sugerencias

- Autocompletado con Tab de comandos, alias y argumentos de ayuda y colecciones.
- Listas de coincidencias con selección mediante teclado y clic, sin ejecución automática.
- Hasta tres alternativas ante comandos desconocidos, presentadas en español o inglés.
- Combobox/listbox accesible, foco visible y conservación del historial y borrador.
- Tab permite salir cuando el único candidato ya está completo; Shift+flechas conserva la selección de texto nativa.

## v0.1.0 — MVP estable

- Terminal interactiva y comandos configurables.
- Configuración JSON y contenidos remotos, con validación de contratos, referencias y rutas.
- Markdown bajo demanda, historial y comandos integrados help, clear e history.
- Personalización visual y preparación del despliegue estático en GitHub Pages.
